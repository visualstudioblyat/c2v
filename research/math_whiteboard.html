six theorems that let a 16k-line compiler compete with Vitis HLS

01 bounded treewidth → polynomial scheduling NOVEL

Thorup's Theorem (1998) tw(G) ≤ 6    for all goto-free C programs tw = treewidth of the control-flow graph
Bodlaender (1996): NP-hard problems on graphs with treewidth k are solvable in O(f(k) · n) time
For k ≤ 6, scheduling becomes polynomial — not NP-hard
Restricted C (no goto, no recursion, no function pointers) → treewidth ≤ 6 → FPT scheduling → provably optimal in polynomial time

Vitis handles arbitrary C++ where treewidth is unbounded → stuck with heuristics forever. We guarantee polynomial scheduling by construction. Thorup 1998 · Bodlaender 1996 · Gustedt 2002 · de Oliveira 2023

02 Bjorklund non-integer II NOVEL — NO OTHER HLS TOOL

Bjorklund's Algorithm (Los Alamos, 2003) E(k, n) = maximally-even distribution of k events in n slots

E(3, 8) = [1 0 0 1 0 0 1 0]    effective II = 8/3 = 2.67
E(5, 12) = [1 0 0 1 0 1 0 0 1 0 1 0]    effective II = 2.4 Vitis: ceil(n/k) = 3 → wastes 11% throughput
c2v: 8/3 = 2.67 → maximally even, no wasted slots
Toussaint (2005): equivalent to Euclidean algorithm, generates world music rhythms
Clavier & Hanen (2011): optimal non-integer II is necessarily aperiodic (quasicrystalline)
Nuclear physics timing (SNS neutron pulses) → Euclidean rhythms (Cuban tresillo) → pipeline slot allocation

When resources don't evenly divide operations, the optimal schedule is aperiodic. Every HLS compiler rounds up to integer II. We don't. Bjorklund 2003 · Toussaint 2005 · Clavier & Hanen 2011

03 tropical eigenvalue = minimum II IMPLEMENTED

Max-Plus Algebra a ⊕ b = max(a, b)     a ⊗ b = a + b

λ(A) = max over all cycles C of:   Σ weights(C) / |C|

λ = minimum initiation interval The critical path IS the tropical eigenvalue of the recurrence graph
Howard's policy iteration: O(|V| · |E|), empirically O(|V|²)
10-100x faster than LP-based II computation
Tropical semiring (max, +) → matrix eigenvalue problem → Howard's algorithm → instant II computation

Standard HLS uses LP solver for II. We use max-plus eigenvalue — same result, orders of magnitude faster. Cuninghame-Green 1979 · Butkovič 2010 · Cochet-Terrasson 1998 · Howard 1960

04 Shannon entropy → parallelism prediction IMPLEMENTED

Schedule Space Entropy H(P) = Σ log₂(width_at_level_i)

width = |antichain at level i|    (Dilworth's theorem)
predicted_speedup = serial_depth / balanced_depth Brightwell-Winkler (1991): counting linear extensions of a poset is #P-complete
But the level-width approximation is efficient and predictive for bounded-treewidth DFGs
Shen et al. (2020): entropy-directed scheduling matches ILP quality at 294x speed
Information theory (Shannon) → entropy of valid schedules → parallelism upper bound → predicts speedup before scheduling runs

We measure: fd_sum16 predicted 2.10x speedup, actual 2.10x. Validated on 4 benchmarks. Shannon 1948 · Brightwell & Winkler 1991 · Dilworth 1950 · Shen et al. 2020

05 Dilworth's theorem → parallelism bound

Dilworth's Theorem (1950) min chain cover = max antichain width

W/D = parallelism upper bound
W = maximum antichain width    D = critical path depth Dual: Mirsky's theorem — min antichain cover = longest chain length
The maximum number of independent operations in any cycle = W
No schedule can do better than D cycles with W-wide resources
Poset theory → antichain = independent operations → minimum resource count

We compute W and D, report them as the parallelism bound. W/D tells you exactly how many functional units you need to fully parallelize. Dilworth 1950 · Mirsky 1971

06 associative tree balancing → O(n) to O(log n)

Reduction Chain Rebalancing a + b + c + d + e + f + g + h    serial depth: 7

((a+b) + (c+d)) + ((e+f) + (g+h))    balanced depth: 3

depth = ⌈log₂(n)⌉    speedup = (n-1) / ⌈log₂(n)⌉ Exploits associativity of +, *, &, |, ^
Always-on in c2v (no flag needed)
Shannon entropy of the unbalanced chain predicts the exact speedup
16-element sum: 15 serial adds → 4 balanced adds → 3.75x speedup
8-element FIR: 7 serial MACs → 3 balanced MACs → 2.3x speedup

Measured: predicted speedup matches actual on all benchmarks. Brent 1974 · Brent's theorem: T_p ≥ T_1/p + T_∞
